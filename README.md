# ServerManager
A tool that lets you easily manage multiple Programs/Servers, works with nearly anything! Uses .sh/.bat files to start the Programs

## In Development!
This tool is nowhere near a stable/easy to use version!

## Currently working commands:
- /start \[program\] (Linux only)
- /kill \[program\] (Linux only)

You can send Commands to single Programs (program command) or to all programs (#command)

Currently there is a **Linux issue**, where the program crashes cause of file permissions
